# PhysioQ NBME Practice App

Static first-year medical physiology question bank app with NBME-style practice blocks, tutor review, normal values, PDF export, highlighting, and answer strikeout tools.

## Online Use

After GitHub Pages is enabled for this repository, the app should be available at:

https://legroj.github.io/PhysioQs/

## Included Question Bank

The static `question-bank.json` file contains 5,100 generated physiology questions. The app loads this file first when hosted online and falls back to the built-in generator if the file is unavailable.

## Duplicate Audit

The June 3, 2026 bank update removes repeated stems and repeated objective-answer variants while preserving 5,100 total questions. Applied vignette questions now use higher projected difficulty values.
